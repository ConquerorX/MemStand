**MemStand** — современный, сверхлёгкий автономный оптимизатор системы Windows, написанный на чистом **C++20** компанией **[Enix Yazılım](https://github.com/enixyazilim)**. Он фиксирует глобальную частоту таймера ядра Windows на **0,50 мс**, устраняя задержку ввода мыши, микрофризы и скачки времени кадра в соревновательных играх, и при этом предоставляет автоматизированное управление памятью с учётом характеристик оборудования.

Созданный по строгому принципу **полного отсутствия внешних зависимостей**, MemStand не требует среды выполнения .NET, WebView2, Electron и фоновых служб. Он тихо работает в области уведомлений, занимая в простое около **1,9 МБ** рабочей памяти и **0,00 %** процессорного времени.

## 🚀 Подробнее: ключевые возможности

### 1. ⚡ Профилирование памяти с учётом оборудования
В отличие от классических инструментов, требующих от пользователя угадывать произвольные значения в мегабайтах, MemStand при запуске определяет объём установленной физической памяти и рассчитывает оптимальные пороги:
- **Порог standby (МБ):** автоматически выставляется на 50 % установленной памяти (`ОЗУ / 2`). Это сохраняет полезный кэш файловой системы Windows в обычном режиме и одновременно гарантирует, что раздутые standby-страницы не отнимут память у запущенных игр.
- **Запас свободной ОЗУ:** динамически масштабируется под класс вашего оборудования (8 ГБ, 16 ГБ, 24 ГБ, 32 ГБ, 64 ГБ+), предотвращая нехватку памяти.
- **Кнопка `⚡ Рассчитать автоматически`:** в любой момент одним щелчком восстанавливает или пересчитывает рекомендуемые параметры под ваше оборудование.

### 2. 🎮 Подавсекундный таймер ядра 0,50 мс + сторож
- Вызывает нативные подпрограммы ядра NT (`NtSetTimerResolution`) вместе с периодами мультимедийного таймера, снижая частоту со стандартных 15,6 мс или 1,00 мс до **0,50 мс** (5000 единиц при точности 100 нс).
- Заметно выравнивает время кадра, снижает дрожание опроса мыши и повышает отзывчивость регистрации попаданий в соревновательных проектах (*Valorant, CS2, Apex Legends, Warzone, Fortnite*).
- **Активный сторож:** постоянно возвращает заданную частоту, не давая Windows или фоновым программам тихо сбросить её в значение по умолчанию. Настраиваемые цели (0,50 мс, 0,75 мс, 1,00 мс, 15,62 мс).

### 3. 🧠 Адаптивная очистка памяти в несколько этапов
- **Этап 1 (обычная нагрузка / игра):** безопасно очищается только standby-список. Рабочие Sets активных процессов остаются тёплыми в кэше — это гарантирует отсутствие микрофризов и потери кадров.
- **Этап 2 (высокое давление памяти):** когда общий объём ОЗУ превышает заданный порог (по умолчанию **85 %**), рабочие Sets и системный файловый кэш аккуратно прореживаются, чтобы избежать зависаний из-за нехватки памяти.

### 4. 📊 Живой индикатор в области уведомлений
- Реальный процент использования ОЗУ выводится прямо на значок уведомлений панели задач с помощью собственной двойной буферизации GDI.
- Цветовая кодировка считывается мгновенно:
  - 🟢 **Изумрудный зелёный:** обычная нагрузка (< 70 %)
  - 🟡 **Янтарный оранжевый:** умеренная нагрузка (70 % - 85 %)
  - 🔴 **Карминовый красный:** высокое давление (> 85 %)
- Контекстное меню области уведомлений даёт ручную очистку в один клик, переключение таймера и проверку обновлений — без открытия главного окна.

### 5. 🛡️ Запуск с повышенными правами без UAC
- Регистрирует нативную запланированную задачу Windows (`schtasks.exe` с уровнем запуска `HIGHEST`).
- Автоматически стартует при входе пользователя с правами администратора — полностью устраняя раздражающие запросы UAC при загрузке.

### 6. 🔄 Встроенная проверка релизов и обновлений
- Лёгкий встроенный проверяющий модуль обращается к API релизов GitHub через `winhttp.dll`.
- Проверяет теги релизов асинхронно, не блокируя интерфейс и не требуя сторонних библиотек.
- Один щелчок — и вы можете скачать новую версию и посмотреть список изменений.

## 📥 Загрузка и установка

MemStand **полностью портативен**: установщик и изменения в реестре не нужны.

1. Скачайте последний `MemStand-vX.X.X-windows-x64.zip` со страницы [GitHub Releases](https://github.com/enixyazilim/MemStand/releases/latest).
2. Распакуйте архив в любую удобную папку (например `C:\Tools\MemStand` или `Desktop`).
3. Запустите `MemStand.exe`.
4. *(Необязательно)* На вкладке **Настройки** отметьте **Запускать вместе с Windows (без UAC)** и **Запускать свёрнутым в трей**, чтобы приложение работало незаметно в фоне.

### Проверка целостности (SHA-256)
В каждый релиз входит файл `checksums.txt`. Проверить целостность загрузки можно через PowerShell:
```powershell
Get-FileHash -Path MemStand.exe -Algorithm SHA256
```

## 💻 Командная строка (CLI)

MemStand поддерживает параметры командной строки для скриптов, лаунчеров игр и автоматизированных пакетных задач:

| Аргумент | Описание |
| :--- | :--- |
| `MemStand.exe -minimized` | Тихо запускается в трее, не показывая окно. |
| `MemStand.exe -purge` | Немедленно очищает standby-список и тихо завершается. |
| `MemStand.exe -clean` | Выполняет полную очистку памяти (standby, рабочие Sets, кэш) и тихо завершается. |

## ⌨️ Глобальная горячая клавиша

- **`Ctrl + Shift + M`**: мгновенно очищает память из любой игры или приложения в полноэкранном режиме, не переключаясь на рабочий стол. Включается и выключается на вкладке «Настройки».

### 🎹 Переназначаемая горячая клавиша

Вы не привязаны к `Ctrl + Shift + M`. Отметьте **«Горячая клавиша очистки»** на вкладке «Настройки» и нажмите кнопку рядом: рекордер переходит в режим ожидания (рамка становится янтарной, а надпись меняется на *Запись...*), после чего нажмите нужную комбинацию.

- Нажмите **`Esc`** во время записи, чтобы отменить, или **`Del`**, чтобы вернуть встроенную `Ctrl + Shift + M`.
- Требуется хотя бы одна из клавиш `Ctrl`, `Alt`, `Shift` или `Win`, поэтому приложение никогда не перехватывает одиночную клавишу.
- Выбор применяется только после нажатия **Сохранить настройки** и сохраняется между перезапусками.
- Если комбинацию уже заняло другое приложение, MemStand сообщит об этом, а не завершится молча, и вы сможете выбрать другую.
- Автоповтор клавиш подавлен, поэтому удержание комбинации не ставит в очередь повторные очистки.

## 🌐 Переводы сообщества (i18n)

MemStand поставляется с **8 языками интерфейса** — English, Türkçe, Deutsch, Español, Français, Italiano, Português (Brasil) и Русский — и поддерживает неограниченное число переводов сообщества через модульные файлы JSON.

Список отсортирован по алфавиту по родному названию языка, а каждый файл в папке `languages/` определяется автоматически при запуске.

1. Скопируйте `languages/template.json` в `languages/<ваш-язык>.json` (например, `languages/german.json`).
2. Переведите значения в блоке `"strings"`. Держите подписи короткими: на экране настроек используются колонки фиксированной ширины, и слишком длинная подпись заезжает на соседнее поле.
3. Перезапустите MemStand — ваш язык сразу появится в меню **Язык**.
4. Откройте Pull Request, чтобы поделиться переводом с сообществом!

## 🛠️ Сборка из исходного кода

### Требования
- Windows 10 или Windows 11 (x64)
- Visual Studio 2022 или Visual Studio 2026 с рабочей нагрузкой *«Разработка классических приложений на C++»*
- CMake 3.20 или новее (необязательно, если собирать через CMake)

### Способ 1: скрипт сборки в один клик
Запустите скрипт сборки в корневом каталоге:
```cmd
build.bat
```
Собранный автономный исполняемый файл появится в `bin\MemStand.exe`.

### Способ 2: CMake
```cmd
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
