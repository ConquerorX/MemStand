# Security Policy

## Supported Versions

Enix Yazılım actively maintains and provides security updates for the latest release branch of MemStand:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **MemStand**, please report it responsibly:

1. **Do not disclose the vulnerability in public issues, discussions, or pull requests.**
2. Send an email to **security@enixyazilim.com** (or open a Private Vulnerability Report directly through GitHub's Security tab: `https://github.com/enixyazilim/MemStand/security/advisories/new`).
3. Include the following details in your report:
   - A description of the vulnerability and its potential impact.
   - Operating system version, build number, and hardware configuration.
   - Proof-of-concept code or step-by-step instructions to reproduce the issue.
   - Any proposed remediation or mitigation.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will investigate and provide regular updates on our progress toward a fix.
- Once a fix is verified, a patch will be published in a new release, and you will be credited for the discovery (unless you request anonymity).
